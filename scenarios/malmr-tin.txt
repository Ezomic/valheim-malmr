# Malmr: tin is never vein mined. With vein mining on and copper open, a pickaxe blow on a tin rock
# lands on the rock the ordinary way, while the same blow on copper goes into copper's bar.
#
# Tin was left out of the Unlocks table on purpose, Robbin's call of 2026-09-26 ("tin doesnt need
# vein mining"), and with no * entry nothing else catches it.
#
# IN 1.0 A TIN ROCK IS NOT A DEPOSIT MALMR READS AT ALL. The first run, on 2026-09-28, put a
# MineRock_Tin down and Devkit's `hurt` answered "not a MineRock5 or a MineRock", and Malmr's own
# deposit list, which names every prefab carrying one of the two, has never named it (see
# malmr-deposits-by-their-drops.txt). Malmr's only ways into a blow are MineRock5.Damage and
# MineRock.Damage, so a blow on a tin rock never reaches it, whatever the table says. The tin half
# therefore asks two things: `malmr progress MineRock_Tin` finds no deposit of that name, and one
# real swing lands - the rock's own ZDO changed, which is the ordinary blow. It used to read
# metal=none open=no and count a hurt chunk, which is the right test for a tin rock that is a
# MineRock, and `hurt` cannot count one that is not. If progress=none starts failing, a game update
# has made tin a MineRock again, and those checks belong back here.
#
# Pickaxes 100 and not 30, so that any tin entry a broken build still carried would be open, and
# Eikthyr seeded so that stone is open as well. The old defaults had Tin at 40 and * at 90, and a
# rock whose tin fell through to its stone would be a stone vein at 20. Neither can reach a tin rock
# that is not a MineRock, but both would be open the day it is one again.
#
# THE CONTROL comes first: a copper deposit, the same pickaxe, the same switch, one swing, and no
# chunk hurt. It stands 4.5 metres out, for the reason malmr-bar.txt gives under WHY 4.5 METRES.
# Then you are moved 12 metres to your right, so the tin rock stands well clear of the copper and no
# swing can reach both. The tin rock is put 2 metres out: at 3, in the first run, its nearest edge
# was 1.9 metres from your eye, and the antler pickaxe reaches 1.8.
#
# NEEDS VANDI for the control, like malmr-bar.txt: copper's and stone's boss halves are seeded
# through Vandi's own kill record, vandi_p_<playerid>_defeated_gdking and _defeated_eikthyr at 2,
# and both keys are removed at the end. A character with real Vandi kills of the Elder or Eikthyr
# in this world loses them.
#
# SINGLEPLAYER, in a TEST WORLD, with the default config. Face open, flat ground, with open, flat
# ground 12 metres to your right as well. `biome Meadows` takes you to the Meadows if you are not
# there, and leaves you where you stand if you are.
#
# It LEAVES BEHIND god and ghost mode on (Devkit cannot switch them off again), a copper deposit with
# one blow in its bar where you started, and a tin rock with one blow in it where you end. Both are
# taken down by the next run's `put`s, which reach 30 metres. Pickaxes is put back, the Vandi keys
# are removed and vein mining ends off. Devkit empties the pack when a run ends and hands back its
# kit.
#
# What a broken build reads:
#   - tin read as a deposit at all: `malmr progress MineRock_Tin` prints a line instead of
#     progress=none.
#   - vein mining broken outright: the copper control reads `hurt` 1 or more.
#
# An ANTLER pickaxe, not the black metal one the other files use: the one a player first mines copper
# and tin with. If the copper `swing` fails naming the tool tiers, the antler pickaxe is below
# copper's, and PickaxeBronze is the next one up. If the tin `swing` fails with nothing changed, read
# its distance first; `swing` names tool tiers only for a MineRock5 or a MineRock, so a tin rock too
# hard for antler would say nothing about it.

god
ghost

# ---- the fixture. Through zero first, for the reason malmr-unlock-levels.txt gives, then the top of
# the skill. The antler pickaxe, for the reason in the header.

skill Pickaxes 0
skill Pickaxes 100

key vandi_p_$player_defeated_gdking 2
key vandi_p_$player_defeated_eikthyr 2
wait 2
keyis vandi_p_$player_defeated_gdking 2
keyis vandi_p_$player_defeated_eikthyr 2

give PickaxeAntler:1
tool PickaxeAntler

biome Meadows

# Copper is open, and the table has no tin in it at all. The "no" is safe to trust because the lines
# above it prove the report printed.

console malmr
printed bosscount=vandi yes
printed Copper unlock=30 open=yes yes
printed Stone unlock=20 open=yes yes
printed Tin unlock= no

console malmr vein on
printed malmr vein=on yes

# ---- the control. Copper vein mines here: one swing lands and no chunk is hurt.

put rock4_copper_frac 4.5
console malmr progress rock4_copper_frac
printed prefab=rock4_copper_frac metal=Copper open=yes yes
printed damage=0.0 yes

swing rock4_copper_frac 1
hurt rock4_copper_frac 0

console malmr progress rock4_copper_frac
printed prefab=rock4_copper_frac yes
printed damage=0.0 no

# ---- tin. Twelve metres to the right, a tin rock 2 metres ahead. Malmr has no deposit of that name
# to read, and the one swing lands on the rock itself. The wait is the game's two seconds between
# teleports, in case `biome` moved you only a moment ago.

wait 2
move 0 12

put MineRock_Tin 2
console malmr progress MineRock_Tin
printed progress=none yes

swing MineRock_Tin 1

# ---- put back what can be put back.

console malmr vein off
printed malmr vein=off yes
unkey vandi_p_$player_defeated_gdking
unkey vandi_p_$player_defeated_eikthyr
skill Pickaxes back
