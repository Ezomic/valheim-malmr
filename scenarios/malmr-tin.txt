# Malmr: tin is never vein mined. With vein mining on and copper open, a pickaxe blow on a tin rock
# knocks rock off it the ordinary way, while the same blow on copper goes into copper's bar.
#
# Tin was left out of the Unlocks table on purpose, Robbin's call of 2026-09-26 ("tin doesnt need
# vein mining"), and with no * entry nothing else catches it. `malmr progress` reads the tin rock as
# metal=none open=no, and one real swing shows the rule acting rather than only answering.
#
# Pickaxes 100 and not 30, so that any tin entry a broken build still carried would be open here.
# The old defaults had Tin at 40 and * at 90, and a * entry catches tin because tin ore goes into the
# smelter. Neither has a boss. So a build like that sends the tin blow into a bar at this level, and
# `hurt MineRock_Tin 1+` fails. At 30 the same build would have hidden behind a shut gate and mined
# by hand, and passed for the wrong reason.
#
# THE CONTROL comes first: a copper deposit, the same pickaxe, the same switch, one swing, and no
# chunk hurt. Without it a hurt tin rock could be vein mining that never worked anywhere. Then you
# are moved 12 metres to your right, so the tin rock stands well clear of the copper and no swing can
# reach both.
#
# NEEDS VANDI for the control, like malmr-bar.txt: copper's boss half is seeded through Vandi's own
# kill record, vandi_p_<playerid>_defeated_gdking at 2, and the key is removed at the end. A
# character with real Vandi kills of the Elder in this world loses them.
#
# SINGLEPLAYER, in a TEST WORLD, with the default config. Face open ground, with open ground 12
# metres to your right as well. `biome Meadows` takes you to the Meadows if you are not there, and
# leaves you where you stand if you are.
#
# It LEAVES BEHIND god and ghost mode on (Devkit cannot switch them off again), a copper deposit with
# one blow in its bar where you started, and a tin rock with a chunk or more knocked off where you
# end. Both are taken down by the next run's `put`s, which reach 30 metres. Pickaxes is put back, the
# Vandi key is removed and vein mining ends off. Devkit empties the pack when a run ends and hands
# back its kit.
#
# What a broken build reads:
#   - tin classed as a vein: the progress line says metal=Tin, or any metal but none, and at
#     Pickaxes 100 the blow goes into a bar, so `hurt MineRock_Tin 1+` fails and damage is above 0.0.
#   - vein mining broken outright: the copper control reads `hurt` 1 or more.
#
# An ANTLER pickaxe, not the black metal one the other files use. A tin rock is small, and a hard
# enough swing could take every chunk it has at once. Gone is what a broken build filling a tin bar
# would leave too, so `hurt` could not tell the two apart. The antler pickaxe is the one a player
# first mines copper and tin with, and its swing takes far less than black metal's. If
# `hurt MineRock_Tin` still fails because the rock is gone, the swing half of this file has not been
# answered either way, and the progress line before it still stands. If `swing` fails naming the
# tool tiers instead, the antler pickaxe is below one of the two rocks, and PickaxeBronze is the
# next one up.

god
ghost

# ---- the fixture. Through zero first, for the reason malmr-unlock-levels.txt gives, then the top of
# the skill. The antler pickaxe, for the reason in the header.

skill Pickaxes 0
skill Pickaxes 100

key vandi_p_$player_defeated_gdking 2
wait 2
keyis vandi_p_$player_defeated_gdking 2

give PickaxeAntler:1
tool PickaxeAntler

biome Meadows

# Copper is open, and the table has no tin in it at all. The "no" is safe to trust because the lines
# above it prove the report printed.

console malmr
printed bosscount=vandi yes
printed Copper unlock=30 open=yes yes
printed Tin unlock= no

console malmr vein on
printed malmr vein=on yes

# ---- the control. Copper vein mines here: one swing lands and no chunk is hurt.

put rock4_copper_frac 3
console malmr progress rock4_copper_frac
printed prefab=rock4_copper_frac metal=Copper open=yes yes
printed damage=0.0 yes

swing rock4_copper_frac 1
hurt rock4_copper_frac 0

console malmr progress rock4_copper_frac
printed prefab=rock4_copper_frac yes
printed damage=0.0 no

# ---- tin. Twelve metres to the right, a tin rock 3 metres ahead. It is not a vein at all, so the
# blow goes to the rock, and nothing is stored on it. The wait is the game's two seconds between
# teleports, in case `biome` moved you only a moment ago.

wait 2
move 0 12

put MineRock_Tin 3
console malmr progress MineRock_Tin
printed prefab=MineRock_Tin metal=none open=no yes
printed damage=0.0 yes

swing MineRock_Tin 1
hurt MineRock_Tin 1+

console malmr progress MineRock_Tin
printed prefab=MineRock_Tin yes
printed damage=0.0 yes

# ---- put back what can be put back.

console malmr vein off
printed malmr vein=off yes
unkey vandi_p_$player_defeated_gdking
skill Pickaxes back
