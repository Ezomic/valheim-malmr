# Malmr: a swing into the bar wears the pickaxe exactly as much as the same swing by hand. Three hand
# swings are measured first, one at a time, then three vein swings the same way, and every reading
# must be the same number.
#
# Why they should: the bar only replaces what the deposit does with a blow. The swing's own costs
# belong to Attack. DoMeleeAttack takes the wear once per swing that struck anything, the pickaxe's
# m_useDurabilityDrain times the world's durability rate, after every struck chunk's Damage call has
# returned, whatever those calls did. So there are two ways for a build to get this wrong. A throw
# inside Damage aborts the swing before that line, and the swing costs nothing. Or Malmr charges
# something of its own on top, which is what the first mechanic did: a share of the swing's wear for
# every extra chunk it took. Both read a different number in the vein rounds below.
#
# THE NUMBERS. A pickaxe's maximum durability is asset data nothing offline can read, and
# `durability` asks for absolute units, so no number here may depend on the maximum. Each swing
# therefore starts from a sliver: `wear PickaxeBlackMetal 0.001` puts the pickaxe at a thousandth of
# a percent of its maximum, which is a few thousandths of a unit for any maximum under five thousand.
# One swing then takes it to minus one unit, give or take that sliver, whatever the maximum was.
#
# It cannot start from zero. Humanoid.UpdateEquipment unequips any tool at zero or below on the next
# physics step, and Humanoid.EquipItem will not put one back in your hand. The same rule unequips the
# pickaxe right after each swing here, which is why every round wears it back to the sliver, equips
# it again and swings once. The `wait 2` after each swing lets the swing's animation finish, because
# EquipItem also refuses while you are still in an attack.
#
# The hand rounds are the measurement. They expect one unit a swing, the drain an item has unless its
# asset says otherwise, at the default durability rate of one. If they fail, their notes give the real
# reading: put that number into all six `durability` lines and run it again. If every round fails
# with the SAME reading, the rule holds and only the expectation was wrong.
#
# Copper is open (Pickaxes 30, the Elder killed twice) so that the vein rounds really fill a bar. The
# `hurt 0` after each of them is what proves the swing went into it. Without that, this file could be
# comparing a hand swing with a hand swing. Each `swing` is one swing and it must land on the rock, so
# every reading is one swing that struck something.
#
# NEEDS VANDI, like malmr-bar.txt: copper's boss half is seeded through Vandi's own kill record,
# vandi_p_<playerid>_defeated_gdking at 2, and the key is removed at the end. A character with real
# Vandi kills of the Elder in this world loses them.
#
# SINGLEPLAYER, in a TEST WORLD, with the default config and the default world modifiers, because a
# world set to another durability rate changes every number below. Both deposits are put 4.5 metres
# out, for the reason malmr-bar.txt gives under WHY 4.5 METRES, on ground levelled round you first,
# for the reason under FLAT GROUND there. The `stage` does that, to the ground under your feet, and
# the game keeps every point within 8 metres of its own height, so start not at a cliff edge and not
# in water. `biome Meadows` takes you to the Meadows if you are not there, and leaves you where you
# stand if you are. The stage takes down every piece within thirty metres of you, what `put` left
# there and the world's own trees, rocks and deposits included, so not beside a base, and the
# world's own are gone for good.
#
# A `stage` before anything, because malmr-tin.txt, the file before this one, leaves its tin rock
# 1.25 metres in front of where you stand. The third run, on 2026-09-28, started there without
# levelling, 3.4 metres above the ground where both deposits landed (you at 73, their feet at 69.6
# and 69.4).
# The third hand swing and all three vein swings missed, 1.9 and 2.0 metres from the blow's origin
# to the nearest face against the black metal pickaxe's 1.8, so the vein rounds' `durability` read
# the untouched sliver and the bar ended at damage=0.0. Nothing about vein wear was measured there:
# the two hand rounds that landed read -1 each, and the second run's three vein rounds, which landed,
# read -1 each too, which is the rule holding.
#
# It used to step 20 metres to the right instead, clear of the tin rock, and in the fourth run, on
# 2026-09-29, malmr-tin.txt's identical `move` stood you 8.7 metres above the ground on the first
# thing a ray from 200 metres up met there, most likely a tree; see NO `move` in that file. Staying
# where you are keeps you on the ground, and the `stage` takes down what `put` left. It replaces the
# `wipe 12` and `flatten 0 0 10` that stood before the first `put`.
#
# The first run, on 2026-09-28, shows why a `durability` pass says nothing without the `swing` before
# it. Its second deposit stood on the first (the Devkit trouble malmr-bar.txt describes), every vein
# swing missed it, and every vein round still read -1: the swing had struck something, most likely
# the deposit underneath, and Attack takes its wear from any swing that strikes anything. The third
# run's third hand round is the same case: 0 landed on the deposit, and -1 all the same, most
# likely from the ground.
#
# It LEAVES BEHIND god and ghost mode on (Devkit cannot switch them off again), the cleared, levelled
# ground, the ore the hand swings knocked loose, and the second deposit 4.5 metres in front of you
# with three blows in its bar until a `wipe`, a `stage` or the next copper `put` takes it down. The
# pickaxe ends broken, and Devkit empties the pack when the scenario ends, so it goes with the rest.
# That is also why no pickaxe reaches this file worn by another: every file's `give` is a fresh
# one, and the third run's `strip` here found no black metal pickaxe to take out after four Malmr
# files had each given one. Pickaxes is put back, the Vandi key is removed and vein mining ends off.
#
# What a broken build reads: a vein round's `durability` outside -1 give or take 0.05, after a
# `swing` that landed. A swing that lost its wear reads the sliver, "0.0021 of 210" (a Devkit older
# than 686ff58 rounded that to "0 of 210", the same words as a pickaxe worn out, which is how the
# third run's misses were first read). One that paid extra reads below -1.05. A `durability`
# failure after a `swing` that failed with "0 landed" is a miss, and says nothing about Malmr.
#
# If a `durability` line fails with "not carrying any", the pickaxe was destroyed when it broke.
# Vanilla pickaxes are not, so something else in the profile is doing that.
#
# WHAT IT CANNOT SEE: the swing that fills the bar. That one breaks the deposit inside itself, and the
# rest of its chunks then reach a rock that no longer exists, which is where a throw is most likely.
# How many swings a deposit takes is not known in advance, so its wear cannot be counted here.
# malmr-bar.txt runs that swing, and its `logged` lines would show the throw.

god

# own level. Exactly one black metal pickaxe: `strip` takes any other copy out first, because with
